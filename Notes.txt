Creating a Branch and pusing it (upstream)
-----------------------------------------------------------------------------------------------------
git checkout -b "Branch Name"  -> creates a new branch and checkouts to it
git push -u origin BranchName  -> pushes the new branch "BranchName" to remote and sets upstream as we are using -u


How to undo git Add
----------------------------------------------------------------------------------------------
git reset




Upstream Push
-------------------------
upstream can be done by boh the below commands
Both commands do the same exact job
Used only for first push of a new branch
1.git push -u origin devFeature1              -> easier to use and -u is shorthand for for --set-upstream
2.git push --set-upstream origin devFeature1  -> More descriptive
